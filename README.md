Include a very brief summary of your project here and what you changed / added to assignment #3. Briefly (3–4 sentences) answer the following question: did the new technology improve or hinder the development experience?
Not too much changed between Assignment 3 and 4 frontend wise. Because I chose to do TailwindCSS for my framework in A3, all I had to do was to install the vite Tailwind module, which is easier to work with than Tailwind without Vite, as you no longer need to have a command running that builds the tailwind css file, it automatically does it. I have a lot of experience with React, so I think the technology improved the development experience quite a bit. Before this class however, I had never used React with JS/JSX, only TypeScript, so this was a little new to me, but overall I think that the new technology improved my speed of development, and I have an easier time seeing how it all fits together on a page.
